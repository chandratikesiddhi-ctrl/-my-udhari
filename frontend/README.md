# My Udhari Frontend Application

Modern React 19 + TypeScript + Vite + Tailwind CSS client for My Udhari digital khata and credit management.

---

## 🎨 Features
- **Store Owner & Staff Ledger:** Real-time customer balance calculations, khata passbook entries, aging reports, and 8-day reminder management.
- **Customer Self-Service Passbook:** Mobile OTP authentication, view individual transaction history, UPI payment QR code, and statement downloads.
- **Multilingual Support:** English & Marathi (मराठी) localization.
- **Design:** Modern responsive mobile-first UI with rich micro-animations and intuitive workflows.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

App runs on `http://localhost:3000`.
API requests to `/api/*` are proxied to the backend on `http://localhost:3001`.
